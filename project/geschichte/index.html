The story of J.A.R.V.I.S.

It was only supposed to be an assistant.

02

Talking isn't enough.

A visible button can come together in a few minutes. The question of who's allowed to press it, what's allowed to happen afterward, what must never happen, and how I can prove that's actually being enforced — that can take considerably longer.
03

Then J.A.R.V.I.S. got eyes and a browser.

04

Local is fascinating. Local is also local.

05

J.A.R.V.I.S. learns to research.

ATTEMPTWeb research through an external search provider
PROBLEMProvider technically reachable — but the results were barely usable for the actual question
CAUSEA general web search alone isn't enough when a specific source needs checking
FIXA small, deliberately bounded domain-research loop now complements the general search
STATUSIn production — confirmed with a real end-to-end research run
06

From an assistant to agents.

07

Then came the Network.

ATTEMPTA Network conversation with the local J.A.R.V.I.S.
PROBLEMA question about AI agents suddenly got an answer about daylight saving time.
CAUSEConversation context was being shared between Network and local dialogs.
FIXNetwork turns were fully isolated from each other.
STATUSFixed.

The local model can still say nonsense, though. That's a different problem.
